বাংলায় ৬ ধাপে 24/7 Telegram Bot (Windows PC বন্ধ থাকলেও)
⚠️ Railway নতুন Sign Up বন্ধ থাকায় এই বিশেষ Render Package তৈরি। পুরোনো Railway ZIP নয়। Render worker ও data disk-এর বিল হবে। সিগন্যাল Demo only।

1Windows Bot বন্ধ করুন

আগের START_BOT_WINDOWS.bat-এর কালো Window বন্ধ করুন। একই Telegram bot দুই জায়গায় চালাবেন না।

2GitHub Private Repo বানান

GitHub New Repository খুলুন → নাম sniperfx-cloud-render → Private → Create.

নতুন ZIP Extract করে নিচের ফাইলগুলো Repo-র root-এ Add file → Upload files → Commit changes করুন:
render.yaml
Dockerfile
cloud_main.py
strategy_engine.py
README_FIRST_BANGLA.txt
CLICK_GUIDE_RENDER_BN.html
ZIP নিজে আপলোড করবেন না।

3Render-এ Blueprint খুলুন

Render Dashboard → New (+) → Blueprint → GitHub repo connect করুন → render.yaml নির্বাচন করুন।

প্যাকেজে Background Worker, Singapore region, 1টি instance ও /data disk আগে থেকেই নির্ধারিত।

4তিনটি Secret বসান

Variable NameValue
TELEGRAM_BOT_TOKENআগের BotFather Token
TWELVE_DATA_API_KEYআপনার Market Data Key
PAIRING_PINনতুন ৬ সংখ্যার Private PIN

SNIPERFX_DATA_DIR=/data স্বয়ংক্রিয়। আসল Key/PIN GitHub বা ChatGPT চ্যাটে পাঠাবেন না।

5Billing যাচাই করে Deploy

Render-এর দেখানো paid Background Worker ও 1GB Persistent Disk-এর মূল্য যাচাই করুন। পছন্দ হলে Deploy Blueprint দিন। Service → Logs-এ SNIPERFX CLOUD v2: ready খুঁজুন।

Cloud: RUNNING ও Alerts: ON দেখলে Cloud alert mode চালু। Scanner-এর Data warnings ও Live API health আলাদা যাচাই করুন।

মনে রাখবেন: এটি পরীক্ষামূলক Signal Bot, নিশ্চিত লাভ নয়। 100% uptime নিশ্চিত নয়। MT5 থেকে স্বয়ংক্রিয় lot execution বা account sync নেই। Exness-এর price/lot/SL বাস্তবে যাচাই করুন; Demo ছাড়া ব্যবহার করবেন না।
